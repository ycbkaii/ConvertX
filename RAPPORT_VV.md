# Rapport VV

## Description du projet

### Qu'est ce que c'est ?
ConvertX est un outil self-hosted (déstiné à l'auto hébergement personnel). Cet outil est un convertisseur de fichiers qui se veut le plus exhaustif possible (+ de 1000 extensions de fichiers [documents, images, vidéos]).

Cet outil a une interface web et est protégé par un login / mot de passe, si on veut garder un historique de nos fichiers de conversion.
<img src='https://github.com/ycbkaii/ConvertX/raw/main/images/preview.png'/>

### Pourquoi est-il utilisé ?
Cet outil est utile dans l'objectif d'éviter d'utiliser des services tiers sur des serveurs inconnus sur le web sans savoir ce qu'il font avec nos fichiers (la vie privée). Et l'outil permet de facilement convertir un grand nombre de fichiers sans avoir à se renseigner sur les commandes spécifiques adapter pour chaque convertisseur

### En quoi il est intéressant ?
Ce projet est intéressant car il est relativement populaire sur GitHUb (**20k stars**), et nous espérons apporter une contribution en effectuant une analyse sur la vérification et la validation logiciel avec une analyse des tests et une contribution sur des tests qu'on pourrait trouvé qui pourraient améliorer la qualité du logiciel. 

Le Self Hosted devient de plus en plus utilisé, et donc la fiabilité de ce genre de projet est très important.

### Structure et langages
Le langage principale c'est du TypeScript (backend / front-end) utilisant une base de données SQLITE. La conversion de fichier s'appuie sur des outils reconnus comme ffmpeg par exemple (Les outils sont listés dans le Readme.md).
Le projet est distribué sous la forme d'une image docker hebergé sur le github.
